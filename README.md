# คิวว่าง

เว็บบอร์ดจับคู่งานดนตรีกับคนทำงาน ออกแบบให้เปิดได้ทั้งมือถือ แท็บเล็ต และคอมพิวเตอร์

## เปิดดูในเครื่อง

เปิด `index.html` ในเบราว์เซอร์ได้เลย ไม่มี dependency และไม่ต้องติดตั้งอะไร

## เผยแพร่ฟรีด้วย GitHub Pages

1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
2. เข้า **Settings → Pages** ของ repository
3. ใน **Build and deployment** เลือก **GitHub Actions**
4. workflow จะเผยแพร่เว็บให้อัตโนมัติเมื่อ push ไปยัง `main`
5. เปิด URL ที่แสดงในหน้า Pages เพื่อเข้าเว็บ

workflow ใช้ GitHub Pages artifact ไม่ต้องมี build server หรือค่าโฮสติ้ง

## เชื่อมฐานข้อมูลฟรีด้วย Supabase

1. สร้าง project ใน [Supabase](https://supabase.com/) โดยเริ่มจาก Free plan
2. เปิด **SQL Editor** แล้วรันคำสั่งทั้งหมดใน `supabase/schema.sql`
3. ใน **Project Settings → API** คัดลอก Project URL และ publishable/anon key
4. ใส่ค่าลงใน `supabase-config.js`:

	 ```js
	 window.QUEUEWANG_SUPABASE = {
		 url: "https://YOUR_PROJECT.supabase.co",
		 anonKey: "YOUR_PUBLISHABLE_OR_ANON_KEY",
	 };
	 ```

5. commit และ push `supabase-config.js` ไป GitHub; Pages จะ deploy ใหม่และเริ่มแชร์ประกาศผ่านฐานข้อมูล

หากมีฐานข้อมูลอยู่แล้ว ให้รัน `supabase/schema.sql` อีกครั้งเพื่อเพิ่มคอลัมน์เวลาเริ่มงานและอัปเดต policy ให้ใช้วันที่ประเทศไทย ประกาศใหม่ต้องระบุเวลา และค้นหาได้ทั้งวันด้วยช่วงเวลา 00:00–23:59 โดยปล่อยช่องเวลาเริ่มและสิ้นสุดว่างเพื่อดูตลอด 24 ชั่วโมง

คีย์ `anon`/publishable ออกแบบให้ใช้ในเว็บสาธารณะได้ โดยสิทธิ์ถูกจำกัดด้วย RLS ใน SQL นี้ ห้ามนำ `service_role` หรือ secret key มาใส่ในไฟล์ frontend

## ข้อมูลและความปลอดภัย

ประกาศที่ส่งเข้าฐานข้อมูล รวมถึงช่องทางติดต่อ จะแสดงต่อสาธารณะทุกคน โครงการนี้ยังอนุญาตให้ผู้ใช้ทั่วไปอ่านและสร้างประกาศโดยไม่ต้องสมัครสมาชิก แต่ไม่มีระบบแก้ไข/ลบหรือป้องกันสแปม จึงเหมาะกับทดลองใช้ก่อน หากเปิดรับผู้ใช้จริง ควรเพิ่มการยืนยันตัวตน การรายงาน/กลั่นกรองโพสต์ และ CAPTCHA หรือ rate limit ก่อน

เมื่อยังไม่ใส่ค่าใน `supabase-config.js` หน้าเว็บจะแสดงข้อมูลตัวอย่างและเก็บโพสต์เฉพาะในเบราว์เซอร์เดิม
