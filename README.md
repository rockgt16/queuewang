# คิวว่าง

เว็บบอร์ดจับคู่งานดนตรีกับคนทำงาน ออกแบบให้เปิดได้ทั้งมือถือ แท็บเล็ต และคอมพิวเตอร์

## เปิดดูในเครื่อง

เปิด `index.html` ในเบราว์เซอร์ได้เลย ไม่มี dependency และไม่ต้องติดตั้งอะไร

## เผยแพร่ฟรีด้วย GitHub Pages

1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
2. เข้า **Settings → Pages** ของ repository
3. ใน **Build and deployment** เลือก **GitHub Actions**
4. workflow จะเผยแพร่เว็บให้อัตโนมัติเมื่อ push ไปยัง `main`
5. เปิด URL ที่แสดงในหน้า Pages เพื่อเข้าเว็บ

workflow ใช้ GitHub Pages artifact ไม่ต้องมี build server หรือค่าโฮสติ้ง

## ขอบเขตเดโม

ตัวกรองและแบบฟอร์มลงประกาศใช้งานได้ ประกาศใหม่ถูกเก็บใน `localStorage` ของเบราว์เซอร์ที่ลงประกาศเท่านั้น ผู้ใช้อื่นจึงยังมองไม่เห็นข้อมูลเดียวกัน และข้อมูลตัวอย่างที่ติดมากับเว็บเป็นข้อมูลสาธิต

หากต้องการเปิดใช้งานจริงโดยยังเน้นฟรี ขั้นถัดไปคือเพิ่มฐานข้อมูลและระบบยืนยันตัวตนใน free tier เช่น Supabase แล้วเก็บ secret ฝั่ง server ไว้ใน GitHub Actions ไม่ใส่ secret ลงในหน้าเว็บ
